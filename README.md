# 🇬🇧 English Learning Bot (Telegram)

Telegram-бот для вивчення англійської з ШІ-співрозмовником. **Усе безкоштовно**:

| Що | Чим | Ціна |
|---|---|---|
| ШІ (розмова, перевірка, вправи) | Groq API, модель GPT-OSS 120B | безкоштовно, без картки |
| Розпізнавання голосових | Groq Whisper | безкоштовно |
| Озвучка відповідей | edge-tts (голоси Microsoft) | безкоштовно, без ключа |
| База даних | SQLite (файл `bot.db`) | безкоштовно |
| Хостинг | ваш комп'ютер | безкоштовно |

## Функції

- 💬 **ШІ-співрозмовник**: розмова англійською текстом або 🎙 голосовими, підлаштовується під рівень (A1–C1) і виправляє помилки з поясненням українською.
- 🎭 **12 рольових сценаріїв**: кафе, аеропорт, лікар, співбесіда, презентація, переговори, вирішення конфлікту… Після `/end` бот дає підсумок: оцінку, типові помилки й корисні слова, які можна додати в словник.
- 📖 **Особистий словник**: можна додати слово англійською або українською, ШІ сам підбере переклад, транскрипцію і приклад. Є кнопка 🔊 вимова.
- 🧠 **Тренування**: картки з інтервальним повторенням, квіз «обери переклад», складання речень з перевіркою ШІ.
- 📚 **Граматика**: 14 тем з поясненнями і вправами, які ШІ перевіряє.
- 🎯 **Тест рівня**: 12 питань.
- 👥 **Анонімний співрозмовник**: чат 1-на-1 з іншою людиною тільки англійською. Українські повідомлення бот не пересилає, а підказує, як сказати це англійською.
- 🏠 **Груповий чат «English only»** ([@engspeakingclub2](https://t.me/engspeakingclub2), кнопка «🏠 Чат англійською» або `/club`):
  - на українські повідомлення бот відповідає нагадуванням і підказує англійський варіант;
  - хто ігнорує правило, отримує 2 попередження, а далі мут на 1 → 3 → 5 хв (лічильник обнуляється після 30 хв без порушень);
  - смайлики, стікери й гіфки не вважаються порушенням мови, але більше 4 за 20 секунд — спам: 5-те повідомлення видаляється з попередженням, 7-ме дає мут на 2 хв (повторно — 5 хв);
  - адмінів бот не мутить;
  - щодня бот публікує тему для обговорення (`/topic`, `/rules`).
- 🔥 **Мотивація**: XP, стрік днів поспіль, статистика, щоденне слово дня і нагадування.

## Запуск (≈10 хвилин)

### 1. Отримати токен бота
1. У Telegram відкрийте [@BotFather](https://t.me/BotFather) і надішліть `/newbot`.
2. Придумайте назву та username (має закінчуватись на `bot`).
3. Скопіюйте токен вигляду `123456789:AAAA...`.

### 2. Отримати безкоштовний ключ Groq
1. Зайдіть на https://console.groq.com і увійдіть через Google.
2. Відкрийте **API Keys** → **Create API Key** і скопіюйте ключ (`gsk_...`).

### 3. Налаштувати й запустити
Скопіюйте `.env.example` у файл `.env` і вставте свої `BOT_TOKEN` і `GROQ_API_KEY`.

Потім у папці `english_bot` (PowerShell):

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python main.py
```

Якщо в консолі з'явилось `Бот запущено ✅`, відкрийте свого бота в Telegram і натисніть **Start**.

> Бот працює, поки відкрите вікно консолі. На захисті просто запустіть його на ноутбуці.

## Налаштування групового чату
1. Додайте бота в групу (у групі: **Додати учасника** → знайдіть бота за username).
2. Зробіть бота **адміністратором** з правами **«Блокувати користувачів»** (для муту) і **«Видаляти повідомлення»** (для антиспаму). Адмін-бот бачить усі повідомлення, тому вимикати privacy mode не потрібно.
3. Напишіть у групі `/rules`, щоб бот опублікував правила.

Посилання на чат, яке бот надсилає в особистих повідомленнях, задається в `.env` змінною `CLUB_LINK`.

## Як показати «Співрозмовника»
Потрібні два акаунти Telegram, наприклад ваш і одногрупника. Обидва натискають **👥 Співрозмовник**, і бот їх з'єднує.

## Структура
```
main.py          — запуск бота
config.py        — налаштування з .env
ai.py            — Groq (чат, Whisper) + edge-tts
prompts.py       — промпти для ШІ
content.py       — сценарії, теми граматики, тест рівня
db.py            — SQLite: користувачі, історія, словник
moderation.py    — лічильники попереджень, мутів і спаму для групи
daily.py         — слово дня / тема дня
scheduler.py     — щоденні розсилки
keyboards.py     — кнопки
handlers/        — обробники: start, chat, vocab, grammar, placement, partner, group
```

## Якщо щось не працює
- **«ШІ зараз недоступний»**: перевірте `GROQ_API_KEY` або перевищено безкоштовний ліміт (≈30 запитів/хв). Зачекайте хвилину.
- **Модель більше не існує**: вкажіть іншу з https://console.groq.com/docs/models у `.env`, наприклад `GROQ_MODEL=qwen/qwen3.8-27b`.
- **Бот не відповідає в групі**: вимкніть privacy mode (див. вище).
